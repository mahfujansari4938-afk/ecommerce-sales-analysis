E-Commerce Sales Analysis

Project Overview

This project analyzes e-commerce sales data to identify revenue trends, product performance, regional sales patterns, customer types, and payment method preferences.

The project demonstrates how Python and SQL can be used to transform sales data into meaningful business insights and support data-driven decision-making.

Objectives

- Analyze total revenue and quantity sold
- Identify top-performing products
- Compare sales across product categories
- Analyze regional sales performance
- Study customer purchasing patterns
- Analyze payment method performance
- Understand monthly sales trends

Dataset

The dataset contains e-commerce order information, including:

- Order ID
- Order Date
- Product
- Category
- Quantity
- Unit Price
- Sales
- Region
- Payment Method
- Customer Type

Tools & Technologies

- Python
- Pandas
- Matplotlib
- SQL
- CSV

Analysis Performed

Python Analysis

Python and Pandas were used to process and analyze the sales dataset. Matplotlib was used for data visualization and identifying sales patterns.

SQL Analysis

SQL queries were created to analyze:

- Total revenue
- Total quantity sold
- Category-wise sales
- Region-wise sales
- Top 5 products
- Payment method performance
- Customer type performance

Key Business Insights

- Total revenue generated was ₹2,40,850.
- Total quantity sold was 55 units across 20 orders.
- Electronics generated the highest category-wise revenue.
- Laptop was the highest-revenue product in the dataset.
- West region recorded the highest regional sales.
- February 2026 recorded the highest monthly sales.
- Card payments generated the highest sales among the payment methods.

Project Results

The analysis provides a clear view of sales performance across products, categories, regions, months, and payment methods.

The results can help businesses identify high-performing products, understand regional demand, and monitor revenue trends.
