E-Commerce Sales Analysis

Project Overview

This project analyzes e-commerce sales data to identify sales trends, revenue performance, top-selling products, and customer purchasing patterns.

Objectives

- Analyze total sales and revenue
- Identify top-performing products
- Find monthly and category-wise sales trends
- Analyze customer purchasing patterns
- Generate useful business insights from sales data

Tools & Technologies

- Python
- SQL
- Excel
- Power BI
- Pandas
- Matplotlib

Key Analysis

The analysis focuses on sales performance, product categories, revenue trends, and customer behavior to support data-driven business decisions.
