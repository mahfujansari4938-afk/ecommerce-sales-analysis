E-Commerce Sales Analysis

Project Overview

This project analyzes e-commerce sales data to understand revenue performance, product sales, regional performance, customer types, and payment preferences.

The project demonstrates how data analysis can be used to generate meaningful business insights and support data-driven decision making.

Objectives

- Analyze total revenue and quantity sold
- Identify top-performing products
- Compare sales across product categories
- Analyze regional sales performance
- Study customer purchasing patterns
- Analyze payment method preferences
- Understand monthly sales trends

Dataset

The dataset contains e-commerce order information including:

- Order ID
- Order Date
- Product
- Category
- Quantity
- Unit Price
- Sales
- Region
- Payment Method
- Customer Type

Tools & Technologies

- Python
- Pandas
- Matplotlib
- SQL
- Excel
- Power BI

Analysis Performed

Python Analysis

Used Python and Pandas to clean, process, group, and analyze sales data. Matplotlib was used to create sales visualizations.

SQL Analysis

Created SQL queries to analyze:

- Total revenue
- Total quantity sold
- Category-wise sales
- Region-wise sales
- Top products
- Payment method performance
- Customer type performance

Key Business Insights

- Electronics generated strong sales compared with other categories.
- Laptops and monitors were among the higher-revenue products in the dataset.
- Regional analysis helps identify differences in sales performance.
- Payment method analysis provides insight into customer purchasing preferences.
- Monthly sales analysis helps understand revenue changes over time.
